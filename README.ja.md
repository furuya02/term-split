# term_split

[English README](README.md)

iTerm2の画面を分割し、ブロードキャスト入力を有効化するコマンドラインツール

## 概要

`term_split`は、macOS向けのCLIツールです。現在のiTerm2ターミナルを複数のペインに分割し、ブロードキャスト入力を有効にすることで、入力したコマンドを全てのペインに同時に送信できます。複数のサーバーで同じコマンドを実行したり、並列で同一の操作をテストする場合に便利です。

## 機能

- iTerm2のウィンドウを指定した数に分割
- 分割した全ペインを現在のディレクトリに自動同期
- 現在のタブの全ペインにブロードキャスト入力を有効化
- 垂直分割・水平分割の両方に対応
- ブロードキャストモードを無効化するシンプルなコマンド

## 必要条件

- macOS
- iTerm2
- Python 3.6以上

## インストール

```bash
git clone https://github.com/furuya02/term-split.git
cd term-split
pip install -e .
```

## 使用方法

```bash
# 10分割（垂直方向）
term_split 10

# 5分割（垂直方向）
term_split 5

# 10分割（水平方向）
term_split 10 -H

# ブロードキャストを無効化
term_split --off
```

## オプション

| オプション | 説明 |
|------------|------|
| `count` | 分割数（2以上） |
| `-H`, `--horizontal` | 水平分割（デフォルトは垂直分割） |
| `--off` | ブロードキャスト入力を無効化 |

## 動作の流れ

1. 分割したい数を指定してコマンドを実行
2. 現在のiTerm2タブが指定した数のペインに分割される
3. 各ペインはコマンド実行時のディレクトリに自動的に移動
4. ブロードキャスト入力が有効になり、タイプした内容が全ペインに送信される
5. 終了時は `term_split --off` でブロードキャストモードを無効化

## 注意事項

- macOSのセキュリティ設定で、iTerm2へのAutomation権限が必要な場合があります
- 分割数が多すぎると、各ペインが非常に小さくなります
